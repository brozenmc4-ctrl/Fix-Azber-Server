# 🤖 ربات فروشگاه رنک سرور ازبر — Railway

این پروژه شامل **دو بات تلگرام** است:

1. بات اصلی فروشگاه
2. بات مخصوص ادمین برای دریافت رسید و تأیید/رد سفارش

## امکانات

- دکمه‌های Inline تلگرام
- نمایش VIP / LEGEND / NICK
- سیستم خرید
- کد تخفیف درصدی
- ساخت کد تخفیف فقط توسط ادمین
- شماره‌گذاری خودکار سفارش‌ها: #1، #2، ...
- ارسال عکس رسید به بات ادمین
- دکمه‌های ✅ تأیید و ❌ رد
- اعلام نتیجه به کاربر در بات اصلی
- ذخیره سفارش‌ها و کدهای تخفیف در SQLite
- توکن‌ها از Environment Variables خوانده می‌شوند

## اجرای Railway

یک سرویس Worker بساز و این Repository/ZIP را Deploy کن.

Environment Variables را اضافه کن:

- `MAIN_BOT_TOKEN` = توکن بات اصلی
- `ADMIN_BOT_TOKEN` = توکن بات ادمین
- `ADMIN_IDS` = آیدی عددی تلگرام ادمین، مثلاً `123456789`
- `CARD_NUMBER` = شماره کارت
- `CARD_NAME` = نام صاحب کارت

Start Command:
`python bot.py`

## ساخت کد تخفیف

در بات ادمین:

`/coupon AZER10 10`

یعنی کد `AZER10` با ۱۰٪ تخفیف.

## نکته امنیتی مهم

توکن‌هایی که در چت یا جای عمومی منتشر شده‌اند را استفاده نکن. اگر توکن واقعی لو رفته، از BotFather آن را Revoke/Regenerate کن و توکن جدید را فقط داخل Railway Variables قرار بده.

## تغییر قیمت

قیمت‌ها در ابتدای `bot.py` داخل `PRODUCTS` قرار دارند و می‌توانی آن‌ها را تغییر بدهی.
